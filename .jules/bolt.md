## 2026-09-22 - Prisma Foreign Key Indexing\n**Learning:** Prisma does not automatically generate database indexes for foreign key relations in PostgreSQL databases by default, leading to full table scans during JOINs and relation lookups if left unaddressed.\n**Action:** Always add explicit `@@index([foreignKeyField])` directives in the Prisma schema for all `@relation` fields to optimize backend query performance.
